# 镜头检查与返修记录

- 镜号/候选版本、真实文件与摘要：
- 采用角色卡/参考版本、实际提交文本与图片顺序：
- 时长/画幅/音轨、可见单次调用数与后期操作：
- 抽帧覆盖：时间点/密度/关键接触；不称为连续播放审查
- 取用窗口、前镜终点和后镜起点：

| 项 | 状态：PASS / FAIL / WARN / UNVERIFIED / N/A | 时间点与证据 | 处理 |
|---|---|---|---|
| 身份、服装、比例及角色卡不变项 | | | |
| 主体数量、台词/动作归属 | | | |
| 必要动作与因果、终点和交接 | | | |
| 肢体连接、道具接触、穿模 | | | |
| 场景/摄影轴线与相邻接缝 | | | |
| 非预期文字、水印与后期字幕 | | | |
| 适用题材检查（皮肤年龄、古风道具等） | | | |
| 连续动态/闪烁/口型 | | 无连续播放能力时UNVERIFIED | |
| 听感、底噪、多余人声、台词 | | 无试听能力时UNVERIFIED | |

PASS必须说明实际覆盖；静帧正确不能填动态PASS。只要仍有必要事件未成立，不能把缺陷候选写成完整合格作品。非必要停顿/结尾保持可静止，必要动作不能拿静图替代。

- 主控判断：选用 / 裁切可用段 / 局部后期 / 有限重拍 / 受阻
- 本轮最严重缺陷、原因假设、主变量与关联图文修改：
- 首次生成次数、追加重试次数、剩余额度；不在改机位/拆镜时重置总额度：
- 修后改善、回退项与相邻接缝：
- 未解决项及整片如何处理：
- 用户认可：未收到则写未取得；不作为已授权制作和导出的前置门
