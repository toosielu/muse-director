# 镜头检查与返修记录

- 镜号/候选版本、真实文件与摘要：
- 执行方式（可见旁聊/内部任务）、实际任务引用或本地标签、状态与主控回收记录：
- 采用角色卡/参考版本、实际提交文本与图片顺序：
- 时长/画幅/音轨、可见单次调用数与后期操作：
- raw/delivery规格目标与实测、技术状态及规格门结果；硬切/内容仍单独检查：
- 抽帧覆盖：时间点/密度/关键接触；不称为连续播放审查
- 短暂事件：必要次数、源时间窗、目标区域、源/采样帧率、阈值/基线、候选与前后帧证据、覆盖缺口；观察与原因假设分开
- 取用窗口、前镜终点和后镜起点：

- 主控判断：选用 / 裁切可用段 / 局部后期 / 有限重拍 / 受阻
- 本轮最严重缺陷、原因假设、主变量与关联图文修改：
- 提交台账：原镜号、候选/诊断、输入版本/主变量、实际状态/错误原文、输出、扣费证据或未知、累计提交与剩余额度；拒收/无文件也登记，不在改机位/拆镜时重置：
- 原片缺陷区间→取用窗口→全片时间点；裁切/去标后复核画幅、必要动作与接缝：
- 音轨真实来源（原生/TTS/代码合成/素材库/实录/未知）与试听覆盖：
- 电平：算法/单位、采样峰值或真峰值/测量域；不凭正峰值或RMS认定听感/削波
- 实际回传：附件/可访问链接或共享文件，能取得的摘要与图片证据；缺少路径/摘要不伪造
- 修后改善、回退项与相邻接缝：
- 未解决项及整片如何处理：
- 用户认可：未收到则写未取得；不作为已授权制作和导出的前置门
