# 治愈小角色 · healing-ip

配合[主文件](../muse-idea-to-short.md)使用，这里只补治愈题材的经验。

## 故事
一个小角色做一件小事，有一点点困难，最后有一个温暖的结果。节奏慢，留白多，一镜一个情绪动作就够。默认竖屏9:16、无对白、轻音乐加环境声；用户另有要求就照用户的。

## 锚点句怎么写
顺序：**材质/画风 → 物种和名字 → 头身比例 → 脸 → 主色 → 服装 → 标志道具和位置**。

> 羊毛毡质感的小兔岚岚，两头身，圆黑眼，奶白短绒毛，浅棕耳尖，薄荷绿围巾，胸前一枚米白月牙木扣

- 材质只选一种：手绘平涂、羊毛毡、黏土、3D卡通……不要混用。
- 耳朵、尾巴、角、嫩芽这类最容易漂的部位，一定要写清**有没有、什么形状、多大**。
- 道具写1–2件，并写位置（“胸前”“右爪提着”）。
- 会多次出现的小伙伴（萤火虫、小鸟、光点）也写一句锚点：是写实昆虫还是发光小球，什么颜色，多大。
- 定妆图里只放一个角色，小伙伴单独做一张。2026-10-04 的实测里，一张图里同时有小兽和水母，两次生成各挑了一个当主角。

## 好看的镜头
- 小角色的情绪靠**耳朵、尾巴、眨眼、歪头、抱紧道具**表现，比写“开心”有效得多。
- 光是治愈片的一半：暖黄灯光、黄昏、晨光、星光，全片保持同一个光源方向。
- 结尾停在一个能截图做封面的画面：主角中景，表情清楚。

## 常见翻车
- 中途换了物种感（兔变狗、变海豹），或者画风从平涂变成写实毛：每镜都带锚点句和定妆图，生成后对照耳朵、比例、材质。
- 小伙伴形态漂移（昆虫变光球）：小伙伴也要锚点。
- 场景乱跳（室内→草地→室内）：故事板写清每镜地点，换地点要有过渡。
- 结尾拉成大远景、主角小到看不见：最后一镜用中景。
