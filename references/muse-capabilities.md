# Muse 能力与执行适配

## 来源与证据等级

依据用户在2026-10-03提供的《Muse 视频生成能力详解与高效调用指南》，读取修订5。该文由Muse自己撰写；本助手读到了正文，没有取得底层工具定义、真实调用日志或能力复测。下表属于当前Muse自述的项目能力配置，遇到实际界面/回传差异时更新，不能当成已独立验证的官方永久规格。私人原文保留在用户项目内，不随技能分发。

## 生成、后期与审查分开

| 层级 | 指南自述 | 助手据此怎样安排 |
|---|---|---|
| 视频生成 | 独立远程Muse Video；单次约10秒，时长不可控 | 将5秒、8秒等写成目标剪辑窗口，取得原片后实测裁切；不假造duration参数 |
| 生成输入 | 有序文字与图片；不接收视频或音频 | 参考图控制身份与构图，文字控制动作；不要向生成器传视频、声音克隆或视频局部编辑指令 |
| 图像工具 | 支持生成/编辑；声明有media_handle链式传递 | 先修必要关键帧，复用实际可用句柄；缺实际句柄则重新交接，不编造ID |
| 上下文续用 | 声明返回snapshot_id，可用于后续生成 | 仅复用来源、角色状态和采用范围清楚的真实ID，实际确认是否可跨旁聊使用 |
| 生成声音 | 自带合成声音，文字可描述氛围 | 不承诺可关闭生成音轨或用音频参考控制演员；纯净声音需求在后期处理 |
| 后期 | 本地抽帧、剪辑、混音、字幕和封装 | 将素材与生成输入分开；音频文件可用于实际可用后期，不等于生成器接受音频 |
| Muse审查 | 能看抽帧，不能连续播放视频或听音 | 让Muse抽帧与做技术检查；连续动作、听音和口型由有实际能力的助手/用户复核 |
| 配音 | 当前可用TTS表演较平，未提供情感/克隆能力 | 沿用用户采用声音；必要时使用已交接干声，不称近似TTS为克隆或自然表演已通过 |

指南所述VM配置、语言模型身份、扩写内部路径和“情感语音必须本地GPU”等解释只作自述，不由本技能推断后台架构、其他服务能力或普遍硬限制。

## 单次容量的项目记录

记录 `max_clip_seconds`（未测为null）、`planning_clip_seconds`（当前自述下可暂用10）、证据日期/来源、可见生成调用数、原始输出时长及是否后期拼接。10是规划容量，既不表示精确可调参数，也不表示已验证硬上限。用户后来提供的单项目反馈自述三条原片各10秒、剪成30秒；原片与调用未独立复测，不能由该案例证明永久上限或普遍时长不可控。

核验单次容量需要可见单次调用和它的原始输出；检查长片是否由多次输出/硬切整合。无硬切不证明没有拼接，单个40秒成片更不能证明一次生成支持40秒。能力变化时更新共同记录，所有题材读取同一项目容量；能否首尾帧、参考图数量和snapshot均以实际入口核验。不能仅将多张图片按顺序提交便宣称首尾帧模式已启用。

### 输入编译与原样转交

给Muse的消息分成两层：**制作任务**写交接、自检、后期和回传要求；**模型输入**只放已采用的视觉目标、参考顺序、动作、必要声音氛围和限制。管理ID、私人路径、审查历史不塞入模型正文。

指南称Muse必须将收到的生成需求原样转交，由平台另一个组件扩写。要求Muse沿用本轮已采用的模型输入，不自行替换剧情；只在实际可见时记录交给生成工具的文字、参考顺序和设置，隐藏扩写写未知。用户明确要求原词对照时，保留原文不改；用户授权优化时将改进稿与原文分开，按真实采用状态执行。不能保证平台隐藏扩写保持所有细节。

## 关键帧、一致性与旁聊

参考图是重新生成的锚点，不承诺逐帧保持原图。每镜准备必要且可用的关键帧；已有合格图直接复用。肢体、服装或标志性特征在静帧上已错时，先修图再做视频，避免将错误图扩散成后续参考。

Muse旁聊或实际可用的内部独立任务用于隔离执行上下文，snapshot_id延续生成上下文，两者不是同一层。内部任务能力依据实际入口确认，不推断隐藏API；没有用户可见旁聊也可以完成主控派发与收集。新旁聊也可能明确复用采用snapshot，但须确认可访问与兼容；失败/混杂snapshot不作为干净身份锚点。无法确认时重新挂载采用图文。具体隔离见 [实测风险第8项](muse-observed-failures.md#8-一个-muse-旁聊对应一个生成任务)。

## 局部返修的真实路线

当前配置没有生成器视频输入或原片区域编辑：

- 字幕、声音、时间点、转场、封装问题优先做实际可用的本地后期。
- 形象或手部问题可先编辑关键帧、换清楚的机位/姿态，再生成约10秒新候选；从实际回传取可用区间回装，复核接缝和声音。
- 不能把“替换2秒”写成生成器能精确产出2秒或仅改原视频该区间。需要重拍时限定镜头与取用范围，保留原母版作为回退。
- 换角度或遮挡不能藏掉剧情明确要求的接触/交接。音频后期不应顺带重新生成已经合格的画面。

## 抽帧、自检与交付

首中末与每秒抽帧可供Muse初筛，关键接触、转折及缺陷附近按事件加密；不把低频抽帧称为逐帧或完整动态审查。要求Muse返回检查覆盖、缺陷时间点、关键帧/接触表、实际处理和未核验项；其听音与连续播放保持未核验。

对于后期处理声音，工具检测可说明音轨、峰值或某次解码结果，不能证明没有喘息、人声污染或台词错误。取得实际文件后由能真实看听的一方复核，无法完成时继续交付候选与缺项。

配乐、字幕和转场遵循采用方案，不固定所有片用1秒叠化；指南示例混音数值不是通用响度标准。请求实际可下载的附件或可访问文件，而非只有文件名/哈希。

普通MP4按兼容需要请求faststart；[FFmpeg官方说明](https://ffmpeg.org/ffmpeg-formats.html#mov_002c-mp4_002c-ismv)说明其将moov索引移到开头，碎片化输出等情形不适用。封装不修复不兼容编码，也不保证所有客户端秒开；仍需技术检查和实际播放。
