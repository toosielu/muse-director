# 制作与验收流程

## 完整制作主线

按已有材料和实际阶段选择下一步。设计分镜和提示词时用 [制作设计方法](production-methods.md) 提炼镜头职责、参考、空间和动作；下表是质量职责，不强制每一步单独审批或在每个项目产出相同数量文件。首次编译完整Muse消息或需要示范时读 [制作与返修完整示例](worked-example.md)。

| 阶段 | 助手的工作 | Muse 制作与回传 | 本阶段要解决的质量问题 |
|---|---|---|---|
| 目标与创意 | 明确受众、作品效果、时长、画风；发展或修订故事 | 已有素材可先回传作为依据 | 观众是否看得懂，内容是否有吸引力 |
| 剧本与分镜 | 建立因果、人物行动、镜头职责、节奏和可实现调度 | 可按实际能力辅助预演 | 每镜是否有必要，台词与动作是否挤在同一短窗口 |
| 视觉与声音设定 | 沿用采用形象，准备必要角色/场景/道具参考和声音路线 | 按实际能力生成候选设定、关键帧或声音样本 | 身份、画风、空间和声音能否稳定复用 |
| 镜头编译 | 从采用分镜写出精简而明确的参考绑定、动作与表演指令 | 接收实际附件、参考和执行任务 | 制作输入能否表达本镜目标，有无矛盾或错误引用 |
| 代表样片 | 选择真正有风险的镜头，诊断实际回传，改输入或调度 | 制作短样并说明实际结果、未完成项 | 先验证身份、接触动作、声线或同步等关键风险 |
| 正式镜头与粗剪 | 复用通过方案，按场景组织小批任务，指导时序与承接 | 制作镜头，按实际能力提供粗剪或可剪素材 | 长片是否漏镜、重复台词、身份漂移、节奏断裂 |
| 返修与完成 | 定位缺陷和原因，保留合格部分，指导剪辑与声音调整 | 执行局部返修及约定的整合 | 修改是否改善目标，是否引入相邻镜头或音画新问题 |
| 全片验收 | 实际看听完整候选，分别记录检查覆盖和采用状态 | 回传真实成片与约定附件 | 成片达到本次质量要求，未解决项明确可见 |

若 Muse 缺少某个素材、剪辑或声音功能，按真实可用能力准备外部素材或提出处理方案；涉及新增工具、费用或制作路线时遵循用户选择，不默认切换视频生成方。

当前Muse生成与后期限制以 [能力配置](muse-capabilities.md) 为准：不能接收视频/音频作为生成输入，不承诺精确原生对白或口型。原生同步路线只作为待验证候选；必须对嘴的需求先说明能力缺项，讨论符合剧情的调度或已采用后期路线。生成约10秒并实测取用，局部返修不假定生成器支持原片编辑。

Muse投产经验与针对性措施读 [实测风险与处理](muse-observed-failures.md) 的相关章节；检查覆盖和采用判定使用本文件末尾的“审查覆盖”。

## 质量优先级与诊断

质量标准服从作品形态：卡通、漫剧、广告与写实片可以有不同动作幅度和剪辑节奏。先处理妨碍理解、违背采用设定或不能交付的缺陷，再处理用户关心的表现力细节。不要用统一打分或固定重试次数代替实际判断。

每轮返修说明“实际看到/听到什么 → 推测原因 → 本轮改哪项 → 用什么结果判断改善”。原因只是推测时明确标注；不能观看连续视频或试听时，不凭抽帧、台词表或文件名确定原因。

与公开示例或另一个生成结果比较时，读取 [对照与改进实验](comparison-experiments.md)：恢复输入、阻断、替代建议、用户批准和执行产物的变更链，以采用稿的事件与状态链验收，示例差距另轴报告。先确认关键行为与物件交接成立，再评价画面表现；输入、调度、生成和整合层的归因分别保留证据与未知。

| 实际失败 | 优先检查 | 可能的针对性改法 |
|---|---|---|
| 角色、服装或道具变了 | 参考实际是否收到、身份与状态是否绑定正确 | 修正参考绑定与采用状态，再做必要同框短样 |
| 动作没发生、穿模或物件瞬移 | 起止状态、接触关系、动作复杂度及可用窗口 | 明确接触和终点；必要时换机位、拆动作或预演 |
| 画面左右、视线或接缝错了 | 场景地理、摄影轴线、前镜终点和本镜起点 | 修正机位与屏幕左右描述，按真实起止素材衔接 |
| 台词错、声线变或口型不合 | 实际声音参考、原文绑定、模型能力与句长 | 纠正声音路线，实测台词时长并做同步短样 |
| 技术都通过但成片不好看 | 剧情职责、表演节奏、镜头重复、声音与剪辑 | 回到分镜或粗剪调整；不只增加提示词形容词 |

不要连续追加相互矛盾的限制词。输入已经清楚而同一失败持续出现时，改制作方法或调度复杂度，并说明对效果的取舍。遇到无法在实际能力与预算内解决的缺陷，保留证据并提出可选取舍，不无限生成。

## 执行基线

一页工作单足够，包含任务 ID、集数、当前阶段、采用的剧本/画面版本、来源证据、必要约束、待决策项、这次修改和输出。

沿用主入口中的采用链和状态恢复规则。活跃输入只保留本轮采用材料；确认、试配、未定分开。冻结画面可供声音迭代，画面仍有未解决缺陷时继续记录，不能扩大为整片采用。

## 依项目阶段选择交付

下表补充各阶段的轻量记录和检查点；完整质量主线见上文。

| 阶段 | 必要输出 | 检查重点 |
|---|---|---|
| 开发/基线 | 可执行故事和本轮工作单 | 因果、人物身份、采用范围、未定项 |
| 新资产/必要机位 | 少量关键帧与参考图 | 角色识别、道具状态、站位和后镜起点 |
| 高风险动作 | 短动作小样 | 接触、相对运动、结束位置及剪切承接 |
| 声音与粗剪 | 实测声音和全片低成本时间线 | 台词完整、句序、自然停顿、动作窗口 |
| 局部返修/终混 | 完整候选版本 | 本次问题及前后镜头、合格素材复用 |
| 验收/交付 | 实际完整文件和约定附件 | 实时画面与听音、同步、首尾、技术检查 |

先按当前能力与采用决定选择声音路线：

- **独立混音**：先取得采用干声并实测句长，再安排画面窗口及混音；缺干声时可先准备分镜，声音窗口标为待实测。
- **原生同步**：没有可预先取得的干声时，用台词长度、表演和停顿提出预估窗口，标为待样片验证；取得代表样片后实测句长、发音、声线与口型，再更新正式镜头。不能将原生同步必须先有最终干声作为前置条件。

避免为适配窗口极端加速、删关键句或擅换演员。保留已采用的原生对白；剥离污染音轨时按实际缺陷处理。执行限制使用Muse能力配置，研究文档中的其他模型功能不移植为Muse参数。已有片按本轮范围局部修复。

动作要求写成“谁在什么位置，对什么对象做了什么，结束后在哪里”。例如手接触盒子→盒子相对柜台右移→右侧主角接住抱紧。推镜、画面缩放和图层移动分别解释；二维图层动画如果表达了动作和承接，可以成立，无需强制写实表演。

进入逐镜制作时，用 [单镜交接与连续性](shot-handoff.md) 将采用资产、场景地理、起止状态、声音路线和验收条件放在同一份交接单。先锁本轮会使用的资产，不要求提前生成整季所有资产；确认集中在新形象、声音、高风险动作和实际采用决定。已授权且使用稳定资产的镜头可小批制作，同时形成粗剪，不因模板要求逐镜新增审批。

小批生成与整片整合的任务隔离按实测风险第8项执行；项目总记录保持跨任务连续性。

## 最小返修

每个问题维护 ID、时间窗口、观察、必改项、验收条件、状态和证据。状态可用 open / in_progress / closed；全片未审时不能把 closed 用于整片。

每轮只处理影响当前交付的失败项。复核要检查改动及相邻接缝；时长改变先建立镜头映射，不能按相同图片文件名或帧序号假定对应。非阻断风格细节记入润色清单，不重新打开已经成立的动作问题。

连续两轮同一问题未改善时，先比较输入、产物和制作方法，减少动作、缩小目标取用窗口或改为更清晰可观察目标；当前Muse仍按约10秒生成，不冒充可精确生成短样。这个条件是诊断节点，不自动取消用户已授权工作，也不自动追加预算。

## Muse 回传约定

工作单附上以下轻量要求，不强制 Muse 具有不存在的字段/API：

> 回复任务 ID、剧本/画面基线、本轮改动和沿用镜头；给出可播放、可下载文件及对应时间线；逐项说明未完成项。音轨、无声母版、工程或素材清单按项目约定交付。确实可取得时附上附件标识或链接。

没有这些字段时先记录实际可见的文件、来源线程、回传说明及 SHA-256，不伪造 message ID 或 shot ID。

## 审查覆盖

| 结果 | 可以证明 | 不能证明 |
|---|---|---|
| SHA-256 | 报告针对的具体字节 | 内容正确 |
| 元数据/完整解码 | 编码信息、音轨存在、该次解码结果 | 台词正确、画面完整、听感良好 |
| 抽帧/接触表 | 被抽到时刻的形象和构图 | 连续动作、口型、听音 |
| 局部动作测量 | 特定区间的相对运动和承接 | 全片动态通过 |
| 时间线文本 | 制作方报告的句序与入点 | 音轨确实按表执行 |
| 实时完整看听 | 实际检查覆盖及发现 | 未检查版本、用户主观声线认可 |

无法直接听音时可提供播放入口、文本时间线和技术结果，把听感、台词发音与声线判断交给能实际试听的人；不要依据模型名称推断声音通过。

交付判定保留各项证据与缺项。用户要求的完整成片需要完整文件及实际验收；仅提供任务书或样片不能报为制作完成。
