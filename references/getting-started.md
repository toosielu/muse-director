# 开始与环境适配

这个技能指导 AI 助手帮助 Muse 做出尽可能好的视频，不绑定作品、账号、画风或固定镜头时长。用户通过自然语言描述效果，助手负责创作、准备有效制作输入、审查结果并指导返修。Codex 是一种运行宿主；其他助手可读取主体说明和模板，实际接入与工具能力另行适配。

## 三种入口

用户直接在Muse中开始时，将 [独立制作指南](../assets/muse-self-director.md) 交给它作为项目指令，并提供简介或大纲；确认实际可读取，无法读附件时粘贴正文。不要求Muse访问本地目录或安装Codex技能，用户已授权范围内由Muse兼任创作与制作。

| 用户现有材料 | 从哪里开始 | 先交付什么 |
|---|---|---|
| 想法或大纲 | 开始项目 | 要完整动画则自主发展剧本并做到全片；只要方案则交方案 |
| 采用剧本、资产或制作线程 | 继续制作 | 当前阶段、采用版本、镜头交接包与缺项 |
| 候选片和反馈 | 检查返修 | 检查覆盖、定位问题、最小返修单 |

首先沿用用户已经提供的作品目标、时长/画幅、画风与现有材料，围绕其选择的 Muse 制作。完整动画请求默认 [自主成片](autonomous-delivery.md)：未指定的普通创作选择由主控选定后继续，不将建议升级为用户审批项；只集中补齐实际阻断。仅写剧本或方案时按该范围交付。新项目不恢复无关旧剧本和生产任务。

新项目可用 [项目简报模板](../assets/project-brief-template.md)；来源快照配置可用 [工作包模板](../assets/workflow-template.json)。复制到当前项目目录后按实情填写，模板不是已经采用的方案。旧项目直接恢复现有工作单，不新建一套相互冲突的记录。

## 环境与执行能力

首次使用或环境变化时，记录与本轮有关的能力：

- **项目目录**：用户指定的目录及当前采用文件。新项目需要目录时采用工作区内的独立目录。
- **本地工具**：是否有可用 Python；需要媒体技术检查时是否有 FFprobe/FFmpeg。没有时继续准备 Markdown 工作单，具体技术项记录未检查。详细调用见 [本地工具](toolkit.md)。
- **执行平台**：实际使用哪个 Muse 产品；是否已登录、是否有可用浏览器控制或受支持的Muse接口。不要仅凭工具名称认定连接成功。
- **制作能力**：Muse实际图文生成入口、图像编辑、生成容量、画幅、原生声音与后期处理；生成参考和后期素材分开。未确认的能力记为未知，外部模型的专用功能与参数不移植到Muse。
- **执行范围**：沿用当前用户已授权的项目与动作；用户指定的预算、重试限制和交付规格属于项目决定。封装安装不会产生外部操作权限。

只检查当前步骤用得上的能力，不每轮重复探测完整环境。读取用户已有官方界面或配置即可，不提取登录凭证，不自动安装连接器。

首次投产读 [能力配置](muse-capabilities.md) 与 [实测风险](muse-observed-failures.md)，记录生成/后期输入、时长、任务隔离与实际看听能力。来源自述不冒充复测，后续按任务读相关章节。需要看到如何落地时读 [完整示例](worked-example.md)。

| 实际条件 | 本轮可继续的工作 |
|---|---|
| 没有浏览器控制或没有登录 | 准备可复制交接文本、附件清单与验收条件；用户可手动投递 |
| 有可用网页和已有发送授权 | 依 [接入和权限](integration.md) 进行交接并记录实际回传 |
| 希望自动投递，但Muse接口或网页能力未确认 | 先核验可用入口，准备交接文本与必要附件，不猜接口或换生成方 |
| 没有其他短剧技能 | 直接整理简报或按请求写建议稿；保留采用状态 |
| 无法听音或完整播放 | 交付已完成的检查及播放入口，听音/连续动态保留未核验 |

## 面向用户的结果

完整制作中简短报告进展，不把内部工作单变成用户待办。最终先交可播放、可下载全片，再给质量结论与真实缺项；必要记录放附件。只写方案或实际受阻时明确相应范围，不能将准备稿当完整动画。

目录可按实际项目选择；一种简单组织是 `brief.md`、`script/`、`assets/`、`shots/`、`production-control/` 和 `deliveries/`，用到时再创建。给每轮和每镜分配可区分的标识，作品名、角色设定、声线及线程链接留在项目内，不写进共享技能。

设计分镜与提示词读 [制作设计方法](production-methods.md)，生产方法读 [制作与验收流程](workflow.md)，逐镜制作读 [单镜交接与连续性](shot-handoff.md)。不要把准备完成、发送完成、生成完成和验收通过合成一个“完成”。
