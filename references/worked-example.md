# 制作与返修完整示例

这是**虚构教学示例**，用于展示助手怎样把采用分镜编译成Muse任务，并依据回传安排返修。没有真实素材、生成、看听、平台ID或改善测量；下文的候选A/B/C和观察都是教学假设，不能写进实际项目的验收证据。实际方法见 [制作流程](workflow.md) 与 [能力配置](muse-capabilities.md)。

## 1. 简报与采用条件

假定用户采用以下教学设定：卡通点心店，一位成年店员把最后一盒点心从柜台A位推到取货B位，松手后微笑；下一镜从盒子已在B位开始。横屏16:9，目标取用约8秒，无对白、字幕或音乐，只要必要动作音。

先保留已有角色、柜台和蓝色纸盒设定。生成容量按当前Muse自述约10秒且不可控，8秒只作为后期取用目标。一次一个主要动作主体；核心通过条件是手实际接触纸盒、纸盒相对柜台由A到B、松手后盒子停在B。笑容和漂亮画面不能替代这条状态链。

## 2. 参考准备与关键帧

教学别名不是平台标签，也不代表文件已存在：

| 必要材料 | 本镜用途 | 实际使用前需完成 |
|---|---|---|
| 角色基准 | 固定脸、发型、制服、比例和卡通画风 | 取得真实采用图并交接，记录实际引用 |
| 柜台/纸盒参考 | 固定A/B位置、蓝色盒子形态和光线 | 使用真实参考；检查盒子数量与场景空间 |
| 本镜关键帧 | 角色右手靠近A位纸盒，左手停在腿侧 | 合格图复用；形态已错时先图像修复 |

生成输入只含实际可用图片和文字。没有真实参考时先准备任务，不编造上传编号、media_handle或snapshot_id。能使用已有干净句柄时确认来源、采用状态和可访问性，否则重新交接。

## 3. 分镜编译

| 取用窗口内的节拍 | 可见事实 | 声音与承接 |
|---|---|---|
| 开始 | 同一角色、一个盒子在A位；右手靠近盒后侧，左手在腿侧 | 无对白，只保留必要环境 |
| 接触与推动 | 右手掌接触盒后侧，持续推动；盒子相对柜台向B移动 | 按实际接触时间放摩擦声 |
| 停止与松手 | 盒到B位停下，右手才松开；没有穿模或瞬移 | 停止后摩擦声结束 |
| 结束 | 盒仍在B位，角色微笑看向盒子 | 可接下一镜，留剪切余量 |

这是导演目标，不是对Muse生成器的精确时间轴参数。不能强拉速度或删掉必要动作来凑8秒；回传后以实际动作窗口确定取用点。

## 4. 第一次给 Muse 的完整消息

下面是**需替换为真实采用素材后才能交接的教学稿**。模型输入与制作管理分开；新旁聊只带当前任务。

> **制作任务：S01 / 输入v1**
>
> 用这次实际交接的角色、柜台与关键帧参考制作一个单人卡通镜头。目标是成年店员把一个蓝色点心盒从柜台A位推到B位，停下松手后微笑；沿用采用画风、人物与道具，不另写剧情。
>
> 请按当前约10秒的生成能力完成候选，返回原片和实测时长。最终希望取得约8秒可用动作段，取用点由实际结果决定，不能为了凑时长删掉接触或松手。不要求生成器接受8秒参数。
>
> **交给视频工具的图文输入：**
>
> 图片按实际交接顺序提供：采用角色基准、柜台/盒子参考、本镜关键帧。固定中景，柜台A位在画面左侧，B位在右侧，一个蓝色纸盒起初位于A。保持参考中的成年店员身份、制服、比例和卡通画风。右手靠近并接触盒子后侧，再沿柜台表面把盒子推向B；移动由手与盒子的接触造成，柜台和背景保持稳定。纸盒到B位停下后右手松开，左手保持在腿侧，最后微笑看向纸盒。一个角色，一个纸盒；只保留必要摩擦声，无台词、额外人声、喘息、字幕和水印。
>
> 请沿用这段已采用输入转交，不再自行替换动作与结局；能取得真实调用文字、图片顺序或设置时一并说明，后台扩写不可见则写未知。
>
> **后期与回传：**
>
> 抽帧覆盖首末、接触、移动和松手附近，说明采样范围、穿帮及处理。Muse不能连续看听的项保留未核验，后续由助手/用户复核。原片自带声音先留存；最终音轨仅允许采用动作声。若实际能做声音后期，可另给去掉生成原声、只混必要动作音的候选；不要声称已试听。
>
> 返回可下载原片、可取得的抽帧/接触表、实际采用参考、真实可用的生成上下文标识、已处理和未完成项。不会取得的字段不要编造。

## 5. 假设收到候选 A：如何诊断

教学假设：Muse返回真实文件但未试听；抽帧中角色和盒子形态稳定。能连续播放的审查者发现，右手掠过盒子上方，而盒子仍留在A位；关键推动没有发生。

- **观察**：身份初筛合格，核心接触/移动失败。具体窗口应在真实文件上定位，这里不编造绝对时间码。
- **假设**：从未接触姿态开始，可能导致动作调度失败；这不是已证明的模型原因。
- **本轮主变量**：改为清楚的首帧接触姿态。采用角色、盒子、画风、场景、机位及主要剧情不变。
- **必要关联改动**：关键帧右手姿态与文字同时更新；记录这是一个输入方案调整，不能声称隔离了一个词的效果。

先编辑或准备采用角色的接触关键帧，不能把手藏起来省掉推盒。候选A原片保留作回退与比较。

## 6. 第二次给 Muse 的返修消息

> **新生成任务：S01 / 输入v2，关联候选A**
>
> 这轮只改善右手与纸盒的接触调度，沿用同一角色、柜台、纸盒、画风、机位和结局。新的旁聊中重新提供本轮必要参考；有来源清楚且实际可用的干净句柄可明确复用。不要带入旧失败提示词全集。
>
> 先确认新的关键帧：右手掌已贴住A位纸盒后侧，手腕和前臂连接自然，左手仍在腿侧；一个人、一个盒子。图像有错先修，不拿错误图生成。
>
> **交给视频工具的图文输入：**
>
> 使用本次真实交接的角色、柜台/纸盒和接触关键帧。固定中景，保持采用角色身份、制服、比例和卡通画风。首帧蓝色纸盒位于柜台A位，右手掌已接触盒后侧。右手保持接触，沿柜台向右把纸盒推到B位；柜台和背景稳定，纸盒相对柜台真实移动。到B位后盒子停止，右手再松开；左手自然停在腿侧。结束时盒仍在B，角色微笑看向盒子。保持手臂与道具连接合理，一个角色、一个纸盒；只要必要动作声，无台词、额外人声、喘息、字幕或水印。
>
> 用当前生成能力返回原片与实测时长，保留完整动作和可剪切余量。抽帧重点覆盖接触、移动和释放，回传处理与缺项。约8秒是后期取用目标，连续动态和听音仍需外部实际复核。

## 7. 假设候选 B 动作改善，但声音污染

假设有实际能力的一方连续播放确认接触、A到B移动与松手成立，但真实试听发现一段未要求的喘息。此时只记录相应动作改善；声音仍不合格，候选B不作为完整成片通过。

本例无对白，下一轮优先做声音后期，保留候选B画面。消息可写：

> 沿用本次实际回传的候选B画面，仅重做声音整合，不重新生成画面。保存原片；移除污染的生成原声，再按实际接触与移动时间混入采用的盒子摩擦/落位声，其他部分保持安静，无人声、喘息或音乐。若没有分轨，这个无对白镜头可以重建音轨；不要以普通降噪保证能消除人声。返回处理方法、可下载候选和实际时长，试听由能听音的一方复核。

这不适用于有必要台词的片段：台词与污染重叠时按声音风险规则处理，不能静音删句，也不能擅自替换指定声线。

## 8. 最后怎样检查与记录

候选C是上述后期输出的教学标签，不是实际已得到的文件。取得真实文件后：

| 项目 | 实际需要的证据 | 没有能力时 |
|---|---|---|
| 技术与时长 | 文件摘要、元数据、可用完整解码；原片/取用段映射 | 保留未检查 |
| 身份与画风 | 采用参考与关键采样对照 | 只说明采样覆盖 |
| 完整动作 | 连续查看接触→相对移动→停止→松手 | 不以抽帧宣布完整通过 |
| 声音 | 实际试听，无多余人声，动作音入点自然 | 保留未听音 |
| 接缝与交付 | 与下一镜起点兼容，实际文件可播放/下载 | 保留未核验 |
| 用户采用 | 按用户目标与真实采用决定记录 | 保留待决定 |

本例无对白，口型项可记“不适用，依据采用简报无对白”，不伪造对嘴通过。技术封装按交付需求处理；faststart不是内容正确或播放秒开的保证。

只有真实复核覆盖支持时，才能说哪项改善、是否采用。示范不预填“全片通过”，不据虚构候选增加Skill评分。真实试验可用 [实验单](../assets/experiment-template.md)，记录前后文件、输入、主变量、回归与实际耗费；本轮没有这些资料时保留“方案已准备、效果待验证”。
