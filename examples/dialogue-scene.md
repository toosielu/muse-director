# 示例：两人对话戏怎么拆

教学示例，还没有拿去生成。展示[主文件](../muse-idea-to-short.md)第5节：台词多的时候，怎么安排原生对白和画外音。

## 用户说
> 30秒古风短剧：雨夜客栈，女侠来找掌柜打听一个人。掌柜先装不知道，最后递给她一封信。

## 说话方式
台词一共四句，都很短，适合**原生对白**，用正反打让每镜只有一个人说话。女侠读信的内容比较长，用**画外音**，画面拍信纸和她的表情，不对嘴。

## 故事板
```
片名：雨夜来信｜30秒｜16:9｜写实仙侠，冷色雨夜，烛光暖色点缀
角色锚点：
  女侠：二十岁左右，高马尾束银冠，月白交领短打外罩墨青半臂，黑色革腰带，腰挂白玉箫
  掌柜：五十岁左右，圆脸短须，灰褐布袍，头戴黑色小方巾，手边一把旧算盘
场景锚点：
  客栈大堂：雨夜，木质柜台，柜台上一盏烛台，门外雨帘，光从柜台烛火来
说话方式：四句原生对白（正反打）＋结尾一段画外音
```

|镜号|秒数|画面一句话|景别|台词|和上一镜怎么接|
|---|---|---|---|---|---|
|1|6|女侠推门进来，抖掉斗笠上的雨|全景|无|开场，交代地点|
|2|6|女侠站在柜台前，看着掌柜开口|中近景，从掌柜身后拍女侠|女侠：“我找一个人。”|全景→中近景|
|3|6|掌柜低头拨算盘，不抬眼|中近景，反打|掌柜：“客官，小店只管住宿。”|正反打，视线相对|
|4|6|女侠把玉箫放在柜台上，盯着掌柜|近景|女侠：“他叫我来的。”|换回女侠，更近一级|
|5|6|掌柜停手，叹气，从柜台下抽出一封信递过去；女侠展开信|中景，两人同框|画外音（女侠心声）：“三日后，城西渡口……”|唯一同框镜，只有递信一个动作|

## 关键写法
- 每句台词约10字，说话人站定或坐定，正面或3/4侧面。
- 第2、4镜拍女侠，第3镜拍掌柜，机位方向相反，视线对得上，剪起来就是正常的对话节奏。
- 递信是唯一的接触动作，单独放在一镜里，写清“掌柜右手递信，女侠双手接过”。
- 画外音后期配，第5镜生成时不用让任何人张嘴。
- 每镜都传对应人物的定妆图，第5镜两张都传。
