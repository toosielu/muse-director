# 示例：两人对话戏怎么拆

教学示例，还没有拿去生成。展示[主文件](../muse-idea-to-short.md)第5节：台词多、角色要说好几句时怎么安排。

## 用户说
> 30秒古风短剧：雨夜客栈，女侠来找掌柜打听一个人。掌柜先装不知道，最后递给她一封信。

## 说话方式：配音画外音为主
一共四句台词，女侠说两句、掌柜说一句，还有一段读信的心声。每镜分开生成时，同一个人的声音会变，所以：
- 四句台词都用 **TTS 配音**，女侠一个声音、掌柜一个声音，全片固定。
- 画面**不靠对嘴**：说话的人拍背影或过肩，或者拍听的人的反应。只有第4镜让女侠正面说一句短话，用原生对白；如果声音和第2镜的配音差太多，就也换成配音，画面改拍她放下玉箫的手。
- 字幕剪辑时压上去。

## 故事板
```
片名：雨夜来信｜30秒｜16:9｜写实仙侠，冷色雨夜，烛光暖色点缀
角色锚点：
  女侠：二十岁左右，高马尾束银冠，月白交领短打外罩墨青半臂，黑色革腰带，腰挂白玉箫
  掌柜：五十岁左右，圆脸短须，灰褐布袍，头戴黑色小方巾，手边一把旧算盘
场景锚点：
  客栈大堂：雨夜，木质柜台，柜台上一盏烛台，门外雨帘，光从柜台烛火来
说话方式：TTS配音为主（女侠、掌柜各一个固定声音），第4镜试一句原生对白
```

|镜号|取用秒数|画面一句话|景别|台词（谁说、怎么出声）|和上一镜怎么接|
|---|---|---|---|---|---|
|1|6|女侠推门进来，抖掉斗笠上的雨|全景|无|开场，交代地点|
|2|6|从女侠背后过肩拍掌柜，掌柜抬眼看她|过肩中景|女侠配音：“我找一个人。”|全景→过肩，女侠背对镜头不对嘴|
|3|6|从掌柜背后过肩拍女侠，女侠皱眉盯着他|过肩中景，反打|掌柜配音：“客官，小店只管住宿。”|机位反过来，拍听的人的反应|
|4|6|女侠把玉箫放在柜台上，正面看着掌柜|近景|女侠原生：“他叫我来的。”|更近一级，正面|
|5|6|掌柜叹气，从柜台下抽出一封信递过去；女侠展开信|中景，两人同框|女侠心声配音：“三日后，城西渡口……”|唯一同框镜，只有递信一个动作|

## 关键写法
- 女侠和掌柜各做一张单人定妆图。第5镜的首帧图里两人都要在，并且都要和定妆图对得上。
- 第2、3镜是正反打，机位方向相反、视线对得上，说话的人背对镜头，所以不用对嘴。
- 第4镜是全片唯一的原生对白：一句话，人站定，正面近景。
- 递信是唯一的接触动作，单独放在一镜里，写清“掌柜右手递信，女侠双手接过”。
- 配音和字幕都在剪辑时加，生成视频时提示词里不写台词，只写表情和动作。
