# 示例：两人对话戏怎么拆

教学示例，未实测。展示[主文件](../muse-idea-to-short.md)第5节：默认原生对白时，对话戏怎么安排；不保证这样拆就能解决声音和口型问题。

## 用户说
> 30秒古风短剧：雨夜客栈，女侠来找掌柜打听一个人。掌柜先装不知道，最后递给她一封信。

## 说话方式：默认原生对白
- 用**正反打**：每镜只拍一个人说一句话，说话的人站定或坐定，正面或3/4侧面。
- 本例补写短句，减少一镜的内容；已有长台词保留原话，需要拆句时提出方案，不强行删短。
- 女侠和掌柜各有一句**声音锚点**，每镜原样带上。
- 用户没有提供读信台词，本例用信纸和女侠表情收尾。若用户已有读信或心声原句，保留它；默认尝试原生，失败时提供保留原句的拆镜或TTS备选，不能因为声音规则擅自删台词、改成字幕。

## 剧本和分镜表
```
片名：雨夜来信｜30秒｜16:9｜写实仙侠，冷色雨夜，烛光暖色点缀
```

|镜号|地点|画面|景别|运镜|台词|和上一镜怎么接|
|---|---|---|---|---|---|---|
|1|客栈大堂|女侠推门进来（开场就推门），之后站定抖掉斗笠上的雨|全景|固定|无|开场，交代地点|
|2|客栈大堂|女侠站在柜台前，正面3/4看着掌柜开口|中近景|固定|女侠：“我找一个人。”|全景→中近景|
|3|客栈大堂|掌柜低头拨算盘，抬眼说话|中近景，反打|固定|掌柜：“客官，小店只管住宿。”|正反打，视线相对|
|4|客栈大堂|女侠把玉箫放在柜台上（开场就放），然后站定说话|近景|固定|女侠：“他叫我来的。”|更近一级|
|5|客栈大堂|掌柜叹气，右手从柜台下抽出一封信递过去，女侠双手接过|中景，两人同框|固定|无|唯一同框镜，只有递信一个动作|
|6|客栈大堂|信纸特写，烛光映在纸上；最后女侠抬眼|特写→近景|缓慢推近|无（信上的字剪辑时压字幕）|从信转到女侠的表情|

## 资产计划和一次锁定
- 人物：女侠、掌柜按实际景别准备面部或全身参考，每张人物卡尽量只画一个人；不强制人人各两张。
- 场景：需要时准备客栈大堂空场景图一张（16:9）。
- 道具：白玉箫、信，重复细节需要定形时准备参考。

以上设定、台词、字幕及分镜都是从简述补写的内容，随剧本、已有图、要补的图和预算一起交用户确认。先按缺图和6张首帧说清要生成多少张图片；视频可报“正片6条，预留2次重做，最多生成8条”。用户同意的数字就是上限，失败和简化后的新生成照计。确认后补图并自主制作；已有自主成片和数量授权就沿用，不逐镜停。合格旧图复用，缺图在已同意的次数内补。

锚点句：
- 女侠：二十岁左右，高马尾束银冠，月白交领短打外罩墨青半臂，黑色革腰带，腰挂白玉箫
- 女侠声音：年轻女声，清亮，语气冷静
- 掌柜：五十岁左右，圆脸短须，灰褐布袍，头戴黑色小方巾，手边一把旧算盘
- 掌柜声音：中年男声，略沙哑，语气圆滑

## 关键写法
- 说话镜都是先做完动作，再站定说一句，动作放在开场。
- 第2、4镜拍女侠，第3镜拍掌柜，计划用正反打；实际视线、机位方向和接缝仍要自查，默认直接切。
- 第5镜首帧需要两个人和场景。一次传入三张参考图是否可用还待测，先核对真实入口，见[多参考图测试](../testing/multi-reference.md)。不能同时传就说明实际用了哪张图、哪些设定靠文字补，不把三个链接或合成图冒充已验证的多图输入。
- 原生对白做不出来时，保留原句，报拆镜、调整姿势和TTS备选；改词、删台词或改无对白先问，已有取舍授权直接执行。声音和口型效果见[最小对白对照](../testing/dialogue-audio.md)，未实测。
