# 示例：带时间码的长提示词 → 拆镜

教学示例，未实测。展示用户已经写好详细提示词时，怎么**保留原话**，只做拆镜和补缺。

## 用户给的15秒提示词
> 16:9，台湾青春剧质感，阴天柔光，浅景深。阿琪，短黑发，蓝色校服外套，白色帆布鞋。校门外的石板路，右侧一辆红色自行车。轻钢琴音乐。0–5秒：阿琪沿石板路跑到自行车旁，缓慢推近后环绕。5–10秒：她右手握住车把，侧头看向左边，喊“等我一下”。10–15秒：她向左挥手，笑着说“我来了”，然后双手回到车把上。

## 第一步：抽出原话（之后每镜原样带上）
- 画风句：`16:9，台湾青春剧质感，阴天柔光，浅景深。`
- 角色锚点：`阿琪，短黑发，蓝色校服外套，白色帆布鞋。`
- 场景锚点：`校门外的石板路，右侧一辆红色自行车。`
- 声音：`轻钢琴音乐。`

用户没给参考图，就先列资产计划：本例中近景需要阿琪面部参考，场景需要“校门外石板路＋红色自行车”的空场景图（16:9）；全身是否另补，取决于第1镜能否核对外形。已有合格图复用，不先花预算生成再请用户确认。

## 第二步：拆镜
按当前约10秒素材的制作方式，将15秒拆成三镜。时间码先作顺序规划，不能保证生成器按秒执行；按用户的三段动作拆，**原动作和台词原样保留**：

|镜号|用户原句|候选补缺（新增，锁定包里确认）|
|---|---|---|
|1|阿琪沿石板路跑到自行车旁，缓慢推近后环绕。|可在车旁停下接第2镜；这是新增接戏设计，不替换原运镜|
|2|她右手握住车把，侧头看向左边，喊“等我一下”。|补景别：中近景；开头接第1镜结尾的姿势|
|3|她向左挥手，笑着说“我来了”，然后双手回到车把上。|补景别：近景，和第2镜区分|

## 第三步：只提醒，不偷改
发给用户确认时，顺带说明两处风险，**由用户决定改不改**：
- 第1镜“推近后环绕”是两个运镜，可能做得杂乱。可选：只保留推近。
- 第2、3镜默认用原生中文台词；读音、口型和跨镜声线都要检查。站定是减少复杂动作的尝试，本例未实测，不能写成已稳。失败时先保留“等我一下”“我来了”，给出拆镜、调整姿势或TTS备选；改词、删台词和转成无对白都先问，用户已授权的方案直接执行。TTS是否更合适，见[最小对白对照](../testing/dialogue-audio.md)，尚未验证。

剧本、分镜表、资产计划、已有图和额度一次交用户锁定。例如：图片上限6次（面部1、场景1、首帧3、备用1），首次视频3条、返修2条，总上限5次；需要全身参考时也计入图片额度，不默默加图。用户确认后补图、生成、自查、直接切和交片，不逐镜再问。用户说“按原样做”就保留原样；已有额度授权不重复确认，结果不理想再拿着实际片子讨论。

（参考图：第2镜已核对的首帧，比例16:9；可复用第1镜合格画面，缺图则在已确认图片额度内补）
