# 示例：带时间码的长提示词 → 拆镜

教学示例，还没有拿去生成。展示用户已经写好详细提示词时，怎么**保留原话**，只做拆镜和补缺。

## 用户给的15秒提示词
> 16:9，台湾青春剧质感，阴天柔光，浅景深。阿琪，短黑发，蓝色校服外套，白色帆布鞋。校门外的石板路，右侧一辆红色自行车。轻钢琴音乐。0–5秒：阿琪沿石板路跑到自行车旁，缓慢推近后环绕。5–10秒：她右手握住车把，侧头看向左边，喊“等我一下”。10–15秒：她向左挥手，笑着说“我来了”，然后双手回到车把上。

## 第一步：抽出原话（之后每镜原样带上）
- 画风句：`16:9，台湾青春剧质感，阴天柔光，浅景深。`
- 角色锚点：`阿琪，短黑发，蓝色校服外套，白色帆布鞋。`
- 场景锚点：`校门外的石板路，右侧一辆红色自行车。`
- 声音：`轻钢琴音乐。`

用户没给参考图，就先做资产：阿琪的面部特写和全身照各一张（图里只有阿琪一个人，背景简单），再做一张“校门外石板路＋红色自行车”的空场景图（16:9）。和剧本、分镜表一起给用户确认。

## 第二步：拆镜
15秒超过单条约10秒，要拆。时间码不会按秒执行，只用来确定顺序；按用户的三段动作拆成三镜，**动作和台词一字不改**：

|镜号|用户原句|补的东西|
|---|---|---|
|1|阿琪沿石板路跑到自行车旁，缓慢推近后环绕。|结尾补“停在车旁，右手伸向车把”，好接第2镜|
|2|她右手握住车把，侧头看向左边，喊“等我一下”。|补景别：中近景；开头接第1镜结尾的姿势|
|3|她向左挥手，笑着说“我来了”，然后双手回到车把上。|补景别：近景，和第2镜区分|

## 第三步：只提醒，不偷改
发给用户确认时，顺带说明两处风险，**由用户决定改不改**：
- 第1镜“推近后环绕”是两个运镜，可能做得杂乱。可选：只保留推近。
- 第2、3镜是原生中文台词，可能读错或嘴型对不上；而且两镜分开生成，阿琪的声音可能不一样。说话时人是站定的，这一点已经比较稳。如果读错，先加拼音或换个常用说法；还不行就改成无台词的表情镜头，这会改动用户原句，要先问用户。不走后期配音。

用户说“按原样做”，就按原样做；结果不理想再拿着实际片子讨论。

## 第2镜最终提示词
```
16:9，台湾青春剧质感，阴天柔光，浅景深。
阿琪，短黑发，蓝色校服外套，白色帆布鞋。
校门外的石板路，右侧一辆红色自行车。
阿琪站在自行车旁，她右手握住车把，侧头看向左边，喊“等我一下”。中近景，固定机位。
轻钢琴音乐。
（参考图：从第1镜抽出的“停在车旁、右手伸向车把”那一帧，比例16:9）
```
