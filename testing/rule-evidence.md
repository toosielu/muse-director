# 主文件规则的证据与待测项

对应 [v3.3主文件](../muse-idea-to-short.md)，更新于2026-10-05。

主文件写默认怎么做，本表集中记录依据。**单次实测**是本轮A/B的统一证据强度：每题每版仅一次、非盲评，只支持注明的观察，不能证明因果或稳定胜率；“改后待测”表示新默认尚未执行。**已实测**保留用于此前文件记载的具体观察，不表示多次验证；**待测**表示默认效果尚未验证。用户偏好和制作约定不伪装成模型能力结论。

现有证据：[10/03的45秒治愈片](../examples/case-2026-10-03-healing-45s.md)、[10/04能力与生成记录](../examples/case-2026-10-04-capability-test.md)、[20秒仙侠竞速反馈](../examples/case-2026-10-04-xianxia-20s.md)。最后一项是用户转述REPORT与第三方复核，原件未在本轮独立核验；相关“已实测”只标用户报告确实跑过的观察，不代表本轮重新测试。仓库记录的部分外部方法来源为[Jarvis的Muse漫剧文章](https://x.com/jarvis11x/status/2104397648438476868)。教学示例、外部方法、Muse自述和文档检查不计作新实测。

本轮新增：[AB-20261004的5题结果与C1–C6判断](ab-test-2026-10-04.md)，由用户提供，总导演依据抽帧和视频分析评分，未盲评；维护者没有独立重看原片。下表“AB-T1”等均指该文件，不是固定测试集编号。各条基线位置与字符变化也在该记录中。

10/05新增：[声音说明与肯定写法的判断](audio-positive-review-2026-10-05.md)。依据为用户声音反馈、外部方法转述及下列既有记录，**没有新的Muse实测**；新增默认是制作约定，效果待测。两份四条盲测尚未执行。
