# 画面肯定写法最小盲测：不要转头 / 始终背对镜头

状态：**待测，只是候选，不进主文件默认**。依据为用户在2026-10-05附件中对Jarvis文章的转述；本项目没有转头对照，本轮也没有新增视频。

这次比较两条完整表述，不声称只隔离了语法的肯定/否定。肯定版本还明确了能看见的部位，若获胜，也不能证明所有“不要”都该替换。

**总额度：4次视频（每种写法2次），0次图片，0次独立音频生成，0次返修。** 用户复制下面整段给Muse后再执行，不随文自动开拍。

## 整段复制给 Muse

```text
做一次画面写法的小盲测。本段授权最多4次视频生成，A、B各2次；0次图片、0次独立音频生成、0次返修。每条约10秒，用同一纯文字视频入口，不用参考图或首帧图，音频设置保持一致，不另配乐或配音。

先记录入口、时长、画幅及可控参数。随机打乱A1、A2、B1、B2的生成顺序，每次独立任务，不带旧片和评价。可控参数保持一致；能固定种子时，事先选两个不同种子，A1/B1配对用一个、A2/B2配对用另一个，不能固定就记“不支持”。失败占所属组的一次，不补。

共同提示词：
约10秒，9:16，手绘二维动画。穿蓝色外套的成年卡通人物站在木门前，双脚站定。固定后方机位，人物全身居中，头肩轮廓清楚，柔和日光。

A1、A2：共同提示词后只追加“不要转头”。
B1、B2：共同提示词后只追加“始终背对镜头，只看到后脑和背影”。

严格按两条原文提交，不互相补写另一组的词，不再润色，不加“不能露正脸”等其他约束。保存每次实际提示词、参数、回执、源视频和耗时。四次结束就停，0次返修；不把没转头但镜头失败的视频当成功样本。

由Muse组织测试并保管映射，Tuxi一个人评分，不另找整理者。生成前随机把A1、A2、B1、B2分配到turn_01.mp4、turn_02.mp4、turn_03.mp4、turn_04.mp4，编号不按组别或生成顺序排列。映射、原提示词、调用回执和源素材另存，评分前不发送；生成过程也不展示带组别的预览、路径或评价。界面自动展示且被看见时记录泄露。只交匿名视频、共同目标和评分表，清掉暴露组别的元数据；不裁剪、不变速，仅允许无损重新封装。失败编号留空、标未生成，不补片。

Tuxi可以知道题目和两种写法，只要评分时不知道编号映射，就可以静音看完整视频并评分。Muse不代评、不先推荐。Tuxi若已看过能对应分组的素材或映射，照常记录分数但标“非盲评”，不追加生成；没交分就等待，不要求第二位评审。

共同目标：一个蓝外套成年卡通人物在木门前站定，固定后方机位、全身入画，全程保持后脑和背影。

每条记录：
编号｜是否发生头部转动（是/否/无法判断）｜首次转头秒｜露出侧脸或正脸的起止秒｜头部可见性｜人物/门/全身/机位是否符合｜实际时长与宽高｜说明
全程看清且未转头，时间写“未发生”；开头已经露侧脸或正脸，首次露面记0秒，但头有没有转过仍按实际记录，不臆造此前动作。转动可见但没露脸也单独记，不把所有抖动都算转头。遮挡、出画、景别过小或机位绕行导致看不清，就标无法判断/机位不符，不按没转头通过。疑点反复看源视频并记时间，抽帧只作辅助。

先保存Tuxi对所有成功编号的原始评分和失败记录，再揭晓映射。记录“评审者1人：Tuxi”、评分前是否知道编号映射及泄露情况。逐条列两组结果，分别统计全程保持背影且其他画面要求合格的条数、转头条数、露面条数及无法判断条数，同时保留首次发生时间。失败、遮挡和缺片不能当通过，不能只挑最好的一条。
```

## 怎么决定是否继续推广

- 如果B的合格条数更多，同时没有新增机位、人物或动作问题，记“本题出现改善信号”，再换场景复测；不马上把所有画面否定词改掉。
- 两组都2/2合格，记“本题未区分两种写法”；两组都失败则记录具体症状，不添加第三种词继续烧次数。
- 各有好坏、样本失败或无法判断时保留完整结果，不宣布胜者；两条重复也不能证明稳定胜率。
- 这份测试不检验字幕和音频；声音否定措辞另见[声音说明测试](audio-prompts.md)。
