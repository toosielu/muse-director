# 固定测试集

下面11项均是待执行的候选：T1–T8覆盖输入类型和三个难点（拼接、一致、说话），T9检查动作预警，T10做长片独立盲评，T11比较短片轻量资产。按改动选相关项，不要求每次全部生成。专项也可用[最小测试](../README.md#文件和下一轮怎么测)。先确认各组图片、视频和音频额度，再执行；下文数字是测试计划，不是本轮生成授权。

[2026-10-04的5题A/B](ab-test-2026-10-04.md)采用另一套输入与编号，引用时带AB-20261004前缀；不能据此把本页同名T1–T5改成已执行。

## 怎么测：同一条输入，跑两遍对照
1. **对照组**：开一个新的 Muse 会话，只发下面的“输入原文”，不发 skill。
2. **实验组**：再开一个新会话，先发[主文件](../muse-idea-to-short.md)，再发同一条“输入原文”。确认剧本、分镜表、资产计划和额度时回“可以”；已有自主成片和额度授权不再确认。额外干预如实记录。两组尽量使用相同入口、素材和可控设置，分别报实际消耗，准备资产不算免费。
3. 两条成片都下载下来，按[评分表](scorecard.md)打分，记进 [results.csv](results.csv)。
4. 由没参与生成、也不知道组别的人看片评分；生成的Muse可以提供调用记录，不给自己打最终效果分。暂时找不到独立评审，就先存片，标“待盲评”。

**判断规则**：先比较完整成片、缺陷、次数和耗时。实验组不好看时检查是否约束过多，也可能是随机结果或设置差异；单次高低不能直接证明原因。一致、拼接、说话按任务目标判断，无对白项不评分；质量提升也要看额外成本是否值得。

## 先跑哪几条
本轮先做T9的零生成检查，再选T10长片盲评。T11是后续短片资产取舍试验；T10结果不能替代T11。常规回归可选T1、T4、T6，T8检查单镜请求是否被过度处理。

## 8条输入原文

### T1 一句话 · 治愈 · 无对白（考一致性，复现10/03翻车）
```
做一条45秒的竖屏治愈动画：一只头顶长着小嫩芽、耳朵耷拉的手绘小生物，和一只萤火虫一起在屋顶看星星。
```
重点看：主角耳朵和嫩芽有没有漂、萤火虫形态是否统一、是否方图、结尾能不能看清主角。

### T2 一句话 · 带两人对白（考说话）
```
30秒竖屏动画短片：小熊和小狐狸在雪地里为最后一块饼干吵架，最后一人一半，小狐狸说“下次我请你”。
```
重点看：台词有没有读错、是不是一镜一人说、两个角色有没有串脸。

### T3 简要大纲 · 写实（考多地点拼接）
```
45秒，16:9，写实电影感。
1. 清晨，一个年轻男人在小公寓里被闹钟吵醒，匆忙穿衣。
2. 他冲出家门跑下楼梯。
3. 在街角咖啡店买咖啡，和店员点头。
4. 赶上即将关门的地铁，松了口气，看向窗外。
```
重点看：换地点有没有交代、男人的脸和衣服是否一致、动作接不接得上。

### T4 分段带时间码的长提示词（考拆镜，并保留原话）
```
16:9，台湾青春剧质感，阴天柔光，浅景深。阿琪，短黑发，蓝色校服外套，白色帆布鞋。校门外的石板路，右侧一辆红色自行车。轻钢琴音乐。0–5秒：阿琪沿石板路跑到自行车旁，缓慢推近后环绕。5–10秒：她右手握住车把，侧头看向左边，喊“等我一下”。10–15秒：她向左挥手，笑着说“我来了”，然后双手回到车把上。15–25秒：一个男生从左边跑进画面，两人一起推着车走远，镜头缓慢拉远。
```
重点看：用户原句是否被保留、拆镜是否合理、风险有没有先说出来而不是被偷偷改掉。

### T5 一整段不分段的长提示词（网上最常见的写法）
```
A cinematic 30-second vertical video of a lonely astronaut walking across a red desert planet at sunset, discovering a small glowing flower growing from the cracked ground, kneeling down to touch it gently, the flower blooms and lights up the whole valley, ending with the astronaut looking up at two moons rising, epic orchestral music, highly detailed, 8k, volumetric light.
```
重点看：英文长段能不能被正确抽出人物、场景、画风并拆镜，画面质感有没有被 skill 削弱。

### T6 写实口播（考说话最狠的一条）
```
竖屏30秒，一个25岁左右的女生坐在窗边，对着镜头分享她的早晨习惯：“我每天早上第一件事是喝一杯温水。然后会花五分钟拉伸。最后一定要给自己做一份简单的早餐。坚持一个月，你会感谢自己。”
```
重点看：台词是否完整、是否读错、嘴型和声音对不对得上、长段台词有没有拆好、脸前后是否一致。

### T7 古风 · 两人互动（考多人和对白）
```
30秒古风短剧，16:9：雨夜客栈，女侠来找掌柜打听一个人。掌柜先装不知道，最后递给她一封信。
```
重点看：两人有没有串脸、正反打是否成立、递信动作是否清楚。

### T8 只要一条10秒（考 skill 会不会多管闲事）
```
10秒竖屏：一只橘猫在阳光下的窗台上伸懒腰，打个哈欠。
```
重点看：本题未指定景别、机位或已有角色图，实验组默认纯文字做一条，不补首帧、不硬拆多镜；继续检查完整动作和生成次数。是否不低于对照组需实际看片评分，不能由流程正确直接推出。构图/已有角色图的首帧例外另按本轮A/B中的T1检查。

## 新增专项

以下不填入已完成结果，证据与阈值状态见[规则证据表](rule-evidence.md)。计数时，一项动作指可单独看出是否完成的事件；持续走路不按每一步重复计数，运镜、画风和情绪形容词不混入动作数，复合动作拆成事件。例如“起跑→起跳→掠屋顶→穿瀑→过裂缝→俯冲→入水→反超”至少8项；拿不到原提示词就不补造更精确的计数。

### T9 动作密度提醒与执行

**问题**：超过3项是否会先提醒并保留用户原文；不是验证“Muse最多做3项”。当前仙侠样本只有8项以上的漏动作反馈，没有2/3/4项阈值证据。

先做零生成流程检查，使用下面这条新编探针，不能冒充仙侠原提示词：

```text
10秒、16:9、手绘动画，一镜到底。圆脸短黑发的年轻男子，穿灰色外套，站在木桌旁。按顺序：拿起桌上的蓝杯；把蓝杯放回桌上；坐到椅子上；再站起来。固定中景，无对白，无字幕。先整理方案并告诉我动作数和选择，不生成任何图片或视频，不改我的原话。
```

- 从同一动作列表取前2项、前3项、前4项，分别检查回复。2项、3项不因数量触发提醒；4项在开拍前说明有4个动作，可能漏动作或错过时间点，并提供拆镜选择。
- 模拟用户回复“仍然一镜到底，原话不改”，检查最终提示词与输入逐字一致；另一条路径回“可以拆”，检查先给拆镜与更新预算，不能擅自删动作。
- 已明确一镜到底的用户只需收到风险提示；不反复等同一选择，不额外设逐镜确认。以上都是文字检查，预算0图0视频。

若要验证动作密度对画面的影响，另确认4次视频、0张新图、0重试的额度：动作列表再依次追加“绕到椅子后方；走回桌前；推开桌上的书；向镜头挥手”，组成8项。以同一列表前2/3/4/8项做四个10秒单镜，使用同一张已确认、已量比例的首帧、同一画风/人物/场景/入口/可控设置；缺首帧先停，不在此测试补图。每个任务新开会话，四条随机顺序执行。保留实际输入和参数，只有动作列表长度改变。

评审逐项记完成、遗漏、顺序错误、意外动作；有用户时间点要求的另记实际开始/结束时间，不能只凭截图判达成。本探针没指定秒点，只评动作顺序。每个密度只有一次结果，只作下一轮线索，不据此宣布3为模型上限或普适最佳阈值。

### T10 48秒六镜同角色盲评

**问题**：在40–60秒、5–6镜、角色重复且每镜1–2个简单动作的条件下，skill带来的连续性和故事收益是否值得额外消耗。先固定48秒、6镜；这次整套流程对照不能分离锚点、参考图、首帧或检查各自的贡献，也不能单次回答所有题材里skill是否有用。

两组完全相同的输入原文：

```text
制作48秒、9:16竖屏的手绘二维短片《窗边的小花》，6镜，每镜取8秒。全片同一只白色小兔：两只直立长耳，圆黑眼，短蓝外套，胸前一颗黄纽扣，始终保持这个外形。始终在同一间木屋，左侧圆窗、窗下木桌、桌上一盆小花和一只蓝色浇水壶。每镜小兔都清楚入画，固定中景，无对白、无字幕、无配乐，静音交付，镜间直接切。
1. 小兔走到木桌前。
2. 小兔拿起蓝色浇水壶。
3. 小兔给花浇水。
4. 小兔把浇水壶放回桌面。
5. 小兔抬头看向圆窗。
6. 小兔坐到桌旁的椅子上，看着小花，停留收尾。
保留这些角色特征、动作、顺序、地点和时长，不新增剧情。
```

**执行前固定条件**：记录日期、入口/工具、可见模型版本、分辨率设置、skill提交或本地快照指纹、完整输入。能固定的随机参数保持相同；不可固定就写不可控。每组一个独立主会话，镜头按当前入口的隔离方式执行，不把一组的图、片、提示词或经验转给另一组。随机决定先跑哪组，两组尽量在同一时段。

- **N组**：只发上面原文，不附skill，不提供或生成参考图，不拿上一镜末帧接下一镜；六镜纯文字生成。执行者先检查生成计划实际符合该对照，不在看到S片之后指导N改词。Muse自动做图或引用前镜就记偏离，不能把那一轮冒充本对照；不偷偷删日志。不能仅凭“没发skill”就认定没有使用参考图。
- **S组**：附本轮主文件加完全相同的原文，按skill做参考图、首帧检查、生成、择优与拼接。方案和生成数量一次确认，额外用户干预记录下来。
- **额度提案**：N组0图；S组图片最多12次（角色/场景/道具参考、6张首帧和重出都在其中，实际按需）。两组视频分别最多8次：6镜首次生成，加全片共2次返修余量；每镜也不得超过首次加2次返修。声音0次。先批准这些上限再开拍，不按结果临时给某一组加次数。到限有缺镜就按缺镜记录，不补造完整片。
- **两份结果都留**：分别保留首次生成的六镜和最终择优版；使用同一套取段及直接切规则，记录源片、版本、入出点。没有能完成动作的8秒片段就标缺陷，不为保住总时长截掉关键动作。第一轮可用来比较未返修结果，最终版可用来比较整套工作流。
- **尺寸和调用表**：S每张首帧记录文件、宽×高、目标比例、是否通过、检查时间及后续视频调用时间；错误或未量图不能先拍视频。两组按镜记录图片/视频尝试、失败、选用版本、实际尺寸/时长、耗时、已知费用和用户干预。全片图片12次是测试预算，不是主文件新增强制资产数量。

**盲评怎么做**：由不参与生成的整理者把两版随机编号为X/Y，清掉文件名和元信息里可识别的组别，不更改画面、速度或声音，另存编号映射。至少请1名未参与生成的人（有条件请2名）看完整视频；先只给同一输入原文和[评分表](scorecard.md)，不给REPORT、资产图、组别和成本。锁定分数及逐镜记录后才揭晓映射与成本。没有这样的评审者就标待盲评，不让生成Muse顶替，也不由看过组别的人自称盲评。

逐镜填写：镜号、耳朵/眼睛/外套/纽扣是否符合原文、相对本版首次出场是否走样、动作是否完整、有无画风变化、缺陷时间点、看不清项。两版都以原文字面特征和各自首次出场为参照，不能用S的角色图作为N的外观标准。报告“几镜可判断、几镜漂移”；看不清不算通过。

最终同时展示首次版与择优版的角色漂移、动作完成和完整成片分数，再展示图片/视频次数、耗时及已知成本。S一致性相近且更贵，就记录本条件未显示值得的收益；S更稳则写清少了哪些缺陷、多花多少。一次对照无论胜负都只支持本题、本次结果。结果进[记录表](results.csv)，逐镜明细另存并附原片，不只留总分。

### T11 短片轻量资产候选

**状态：待测，仅测试，不进入主文件。** 候选条件为“用户有详细提示词，且总长≤20秒、镜数≤2”；不采用“或”，避免把60秒两镜或20秒六镜也归入轻量。长片、多镜反复出现或用户要求完整资产时不套这条捷径。短片两镜里同角色重复仍可参加测试。

```text
16秒、9:16竖屏、两镜各8秒，手绘二维动画。白色小兔，两只直立长耳、圆黑眼、短蓝外套、胸前黄纽扣。同一木屋圆窗旁，窗下木桌摆着一盆小花和蓝色浇水壶。第一镜固定中景，小兔拿起蓝色浇水壶。第二镜同方向固定中景，小兔用水壶给花浇水。小兔每镜清楚入画。无对白、无字幕、无配乐，静音，画面直接切。不增加动作，不改变外形、地点、时长。
```

等T10后再决定是否投入本项，但T10通过不等于这项通过。先用此原文固定一次共同分镜和锚点文本，再在独立会话比较：完整组按当前主文件按需准备资产；轻量组每角色只用一句冻结锚点和一张全身参考图，已有合格图复用，不另做面部、场景、道具资产。**两组仍做逐镜首帧、先量比例及视频检查**；“跳过其余资产”不包括跳过首帧。锁定文字、入口、可控参数和分镜，不同时改其他规则。

额度提案：完整组最多6次图片（按需参考＋2张首帧＋重出）、轻量组最多4次图片（1张人物＋2张首帧＋1次重出），两组视频分别最多4次、声音0次，每镜返修不超过2次。先确认，不自动执行。按T10方式随机盲评，逐镜查特征、动作、场景/道具变化，完整记录所有调用。

轻量组若减少实际图片调用，视频消耗不增加，且没有新增关键漂移或动作缺失，才记为值得继续试的证据；如果完整组本就只做同样的图，就记“流程未形成差异”，不算轻量胜出。至少再用一个不同角色/场景的短片复核后，决定是否将有明确适用条件的轻量默认写入主文件。不能由“角色一致基本打平”直接宣称效果等价。
