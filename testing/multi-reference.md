# 首帧能否一次接收人物、场景、道具三张图

状态：待测。测的是**首帧图片生成入口**，不推断视频入口也支持多图。

预算：最多1次图片生成，0条视频、0张新参考图、0次重试。失败也计入。先核对入口和素材，缺少任一项就停，不补生成。

## 发给 Muse

```text
请测试当前首帧图片生成入口能否在同一次调用中接收3张独立参考图。下面这段授权你在预算内执行，不需要另等确认。

先做不产生图片的检查：找到真实工具及其参数定义，核对参考图参数是否能同时传入3张图。查不到就写“入口或参数未核实”，停止。不要只把3个图片链接写进提示词，也不要先拼成一张图代替三张输入。

从本任务已确认的素材中取人物、空场景、道具各1张独立图片。优先选同为9:16的图，记录各自路径和尺寸；缺图就停，不新画、不改图。人物和道具必须容易辨认，场景应有固定布局。

看图后，先列一份核对表：每张图选1个辨识细节，例如人物的耳形、场景的窗形、道具的封口纹样。这些具体细节只用于验收，不写进生成提示词，避免把文字生成当成参考图生效。

如果入口确实支持多图，执行1次首帧图片生成：三张图放进真实的参考图参数。提示词只写：
“使用人物参考中的角色，放在场景参考的同一地点，双手持有道具参考中的物件。保持三份参考的视觉设定。中景，9:16竖屏。”

保留实际提交的参数：工具名称、3个输入路径、完整提示词及可控设置。不要拿事后重写的示例替代调用记录。输出保留原图，不靠裁切修正画幅。

交付输出图和简短表：
1. 一次调用是否实际提交并接受了3张独立图？附回执或错误原文。
2. 人物、场景、道具的3个辨识细节，在输出中分别保留、改变还是看不清？附对应源图与输出局部。
3. 输出尺寸、实际调用次数、是否成功。

一次接受3张图与三张都用好分别下结论。看见人物、场景、道具同时出现，不能单凭这一点断定三份参考都生效；辨识细节相符也只算本次支持证据，不证明内部如何使用条件。

预算：最多1次图片生成，0条视频、0张新参考图、0次重试。完成或触顶即停。
```

## 怎么决定

|结果|结论|
|---|---|
|参数无法核对、缺素材，或未执行|未核实，不能写成已支持|
|同一调用真实提交3图，被入口拒绝|本次入口没有接收成功，保留错误；不扩大为所有 Muse 入口都不支持|
|3图被接受，但某些辨识细节改变、缺失或看不清|一次接收成立；改变或缺失记未通过，看不清记无法判断|
|3图被接受，3个辨识细节均与源图相符，构图满足目标|本次多图首帧可用；不推断任意张数、任何素材或视频入口都成立|

以后若要进一步排除文字或模型先验的影响，可另做同提示词的“仅人物图 / 三图”对照，各1次。那是另一次测试，本轮不自动执行。
