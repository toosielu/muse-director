# 一句话成片 · muse-idea-to-short

把一句话、大纲或现成提示词交给 Muse，帮助它做多镜头短片：保留你的原意，先规划角色和接戏，再生成、检查和剪辑。

**什么时候用**：超过10秒要拆镜拼接，或需要重复角色、道具和对白连续。

**什么时候别用完整流程**：只要一条约10秒视频，可以直接给 Muse；skill 会按动作、构图和角色要求选择首帧图或纯文字，略过长片确认。

**怎么发**：把[主文件](muse-idea-to-short.md)发给 Muse，读不了链接就贴正文，再给故事或现成提示词。它先交剧本、分镜表、资产计划和图片/视频预算。你回“可以”后，它补图、自查、逐镜生成、剪辑并交片，不再逐镜请你定夺。你要看实图定妆，就提前说。

> 按《一句话成片》做一条30秒、竖屏9:16的治愈动画：蓝外套小兔把迷路的萤火虫带回灯笼。先交剧本、分镜表、资产计划和图片/视频预算，我说可以后自主做到整片；画面默认直接切，原话保留，额度用完先停。

想直接做，补一句：“自主成片，图片最多8次、视频最多6次，失败也计入，不加预算。”数字由你按项目决定，这个例子不是已实测的成功率或最低成本。

**拿到片子先看**：角色和道具是否前后一致、故事动作是否做完、画幅对不对、接缝和结尾是否自然。对白要自己听：字词、声线、噪声和口型不能只看截图判断。

**成本预期**：不再用未经统计的“每镜平均3–4次”估算。开拍前分别列图片上限、首次视频数和返修视频数；所有失败、废弃和简化后的生成都计入。到额度就停，交已有结果和卡点，追加先问你。

## 现在的流程（v3.3 评审稿）

**剧本 → 分镜表 → 资产计划与预算 → 锁定 → 资产和首帧图 → 逐镜生成 → 拼接**

- **原话优先**：已有画风、动作、台词、换场、结尾和音乐保留，只补缺；做不到先说明要改什么。
- **资产按需**：优先复用合格人物、场景和道具图，缺什么补什么；关键特征写进简短锚点句，每镜复用，结果仍逐镜检查。
- **首帧图按目标选**：构图和角色重要时用首帧；大动作可考虑纯文字。起势首帧能否两者兼顾还要测；多图同时作为参考也还没实测。
- **对白默认原生**：保留原台词，失败后说明拆镜、改姿势或TTS备选，让你决定。用户已授权的方案直接执行；不擅自改成无对白。
- **剪辑默认直接切**：时间流逝或换场确实需要时才考虑淡化。音乐和环境声的连续铺设另行安排。
- **返修与额度分开**：每镜累计3次尝试后检查是否简化，不自动放宽到5次；无论选哪条路线，都守整片额度。
- **检查说明范围**：首帧合格不代表视频合格；采样没看见不代表全片没有。不能听、不能量时说明未核实。

这份skill是在逐轮测试的工作流程，没有完整验证全部默认值。六步法、资产先行、复杂动作放开场等建议参考了 [Jarvis 的 Muse 漫剧实战文章](https://x.com/jarvis11x/status/2104397648438476868)，外部方法不等于本项目已经验证。

10/04的一次单图测试得到接近9:16的视频，角色大特征基本保住，小细节仍会变。补画风句的样本没有再次变3D，补场景句的样本没有再次换背景；这支持保留简短提示词模板，尚不足以保证每次成功。一次橘猫对照中，首帧图构图较稳，纯文字动作幅度较大；不把它写成所有镜头的固定规律。

## 给助手宿主使用

```sh

```

调用：`$muse-idea-to-short`。入口是 [SKILL.md](SKILL.md)。
