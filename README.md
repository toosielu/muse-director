# Muse 导演助手 · muse-director

从简介或故事大纲出发，设计故事、分镜、角色与场景参考、Muse生成指令，再根据实际样片安排剪辑、声音处理和局部返修。

Muse是视频制作方。Seedance官方文档和Hell Grind是制作方法的研究来源：提炼参考组织、空间、动作、样片验证和返修思路，再按Muse实际能力设计任务。

## 直接交给 Muse

打开 [Muse自用制作指南](assets/muse-self-director.md)，将文件或正文与故事简介/大纲一起交给Muse，作为当前项目的制作指令。该指南独立可读，无需安装本地脚本。附件读取和工具执行取决于实际环境，尚未验证Muse原生Skill安装。

可附上：

> 请阅读附件《Muse导演助手》，按这份指南负责本项目。我的简介/大纲是：……。请发展可执行故事、分镜与参考方案，并在本次已授权范围内推进样片、剪辑和返修。次要缺项先给建议，关键问题集中说明。

## 在 AI 助手中使用

将整个仓库目录放到助手支持的技能目录，文件夹名保持为 `muse-director`。Codex默认个人目录为 `~/.codex/skills/muse-director`；已配置技能目录时使用相应位置。保留目录结构，已有定制版本先比较再更新。

调用：

> 用 $muse-director 从我的故事大纲开始，沿用确定的角色与画风，准备Muse可执行的分镜、参考和镜头指令。

主入口是 [SKILL.md](SKILL.md)。其他助手可按其支持的技能或指令载入方式读取；网页操作和媒体检查能力需要分别适配。

## 制作主线

简介/大纲 → 剧本与分镜 → 采用资产及声音路线 → Muse镜头输入 → 代表样片 → 正式镜头与粗剪 → 局部返修 → 实际验收。

关键方法见 [制作设计方法](references/production-methods.md)，完整示范见 [制作与返修示例](references/worked-example.md)。示范为虚构教学稿，不是实际生成效果证明。

## 能力与验证范围

当前能力记录来自Muse自述及用户经验，未独立复测；实际入口变化时更新。指南自述单次约10秒、时长不可控、生成仅接收图文，短镜由后期实测取用。Muse可抽帧和做技术检查，连续动态、声音及口型交给能实际看听的一方复核。

本地工具使用Python标准库，媒体技术检查需要实际可用的FFprobe/FFmpeg。缺工具时继续创作和准备，相关技术项保留未检查。本包不提供视频生成服务、账户凭据或自动执行器。

本轮结构和18项本地工具测试通过。这不证明视频质量已改善；Muse端完整执行、其他助手与macOS/Linux兼容性尚未实测。
