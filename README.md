# 一句话成片 · muse-idea-to-short

把一句话、大纲或现成提示词交给 Muse，帮助它做多镜头短片：保留你的原意，先规划角色和接戏，再生成、检查和剪辑。

**什么时候用**：超过10秒要拆镜拼接，或需要重复角色、道具和对白连续。

**什么时候别用完整流程**：只要一条约10秒视频，默认纯文字生成，略过长片确认；明确构图或要对齐已有角色图时才做首帧。高速全身动作优先纯文字，遇到严格构图或外形要求就先定取舍。

**怎么发**：把[主文件](muse-idea-to-short.md)发给 Muse，读不了链接就贴正文，再给故事或现成提示词。它先交剧本、每镜怎么拍、要补哪些参考图，以及大约要生成几张图、几条视频。你回“可以”后，它补图、自查、生成、剪辑并交片。你要先看角色长相，就提前说。

> 按《一句话成片》做一条30秒、竖屏9:16的治愈动画：蓝外套小兔把迷路的萤火虫带回灯笼。先给我制作方案，告诉我大约要生成几张图、几条视频。我同意的数字就是上限；我说可以后，你自主做到交整片。

想直接做，补一句：“自主成片，图片最多8次、视频最多6次，失败也计入，不加次数。”把数字换成你愿意接受的上限。

**拿到片子先看**：角色和道具是否前后一致、故事动作是否做完、画幅对不对、接缝和结尾是否自然。对白要自己听：字词、声线、噪声和口型不能只看截图判断。

**生成数量怎么算**：让 Muse 先报计划数量和重做余量，例如“正片4条，预留2次重做，最多生成6条视频”。图片、视频、配音分别报；失败也算，用完先停，增加次数先问你。

## 现在的流程（v3.3）

**剧本 → 分镜表 → 列参考图和生成数量 → 确认方案 → 生成各镜 → 检查拼接 → 交片**

- **原话优先**：已有画风、动作、台词、换场、结尾和音乐保留，只补缺；做不到先说明要改什么。
- **动作太多先提醒**：一镜超过3个动作，开拍前说明可能漏动作并给出拆镜选择；你坚持一镜到底，就按原话做。
- **资产按需**：复用合格人物、场景和道具图。同地点同机位用第一张布局清楚的首帧作场景总图，近景不硬充总图；每镜另写道具起止状态。接缝生成时按预计取段预查，剪辑后按实际边界重查。
- **按镜头选路线**：高速全身动作优先纯文字；其余多镜头默认首帧。用图先量宽×高，量不到不生成。横屏16:9在开拍前选好画幅方案，纯文字单镜也一样；沿用全片选择，图或视频比例不符先停，同入口重复偏差不自动返修。
- **只写本镜事件**：共用的角色、画风、场景描述保留，动作和台词只放本镜的，不反复塞整段故事。
- **对白默认原生**：保留原台词，失败后说明拆镜、改姿势或TTS备选，让你决定。用户已授权的方案直接执行；不擅自改成无对白。
- **声音先定方案**：每镜写清配乐、具体声源或说话安排，没定时并入一次确认；保留静音、台词和原音效要求。先用原生声音，听不到的交你听，不用音量数字冒充通过。
- **剪辑默认直接切**：时间流逝或换场确实需要时才考虑淡化。不自动另做后期配乐；你要求跨镜连续配乐时，提前确定可用音轨，不把逐镜音乐当同一首。
- **只为具体缺陷返修**：满足硬要求就停，不为“想更好看”盲试。首次加最多两次返修，每镜最多3次视频调用，整片总上限先到就停；保留旧版择优，都不达标就交候选并说明缺陷。
- **被拒先说明**：保留拒绝原文，不自动改词重试。写实真人图生被拒，先核对平台允许的内容与输入方式，再由你决定是否保留动作台词、去图做一次纯文字；不把人脸猜成确定原因。
- **检查说明范围**：首帧合格不代表视频合格；采样没看见不代表全片没有。不能听、不能量时说明未核实。

部分规则还在实测中，状态和依据集中放在[规则证据表](testing/rule-evidence.md)。本轮文字检查见[审查记录](testing/review-v3.3.md)。

