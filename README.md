# Muse 导演助手 · muse-director

给主题、简介、大纲或剧本，让Muse负责分镜、资产、独立制作任务、选镜、有限返修、剪辑混音，并交付完整动画。普通选择由主控决定，用户收到全片后再提修改。

Muse是视频制作方。Seedance文档、Hell Grind及创作评审资料提供可迁移的方法，按Muse当前实际能力使用。

## 直接交给Muse

打开 [Muse独立指南](assets/muse-self-director.md)，将文件或正文与主题/剧本一起交给Muse，并作为本项目的制作指令。

> 请读取并采用仓库里的 assets/muse-self-director.md，负责完成完整动画。主题/剧本：……。普通创作、分镜、镜头选用、有限返修、剪辑混音由你自行决定。通过实际可用的独立旁聊或内部任务生成，主动收齐结果并继续整合，不让我逐镜确认。请交可播放、可下载的全片，简短注明真实缺项和未核验项。

可补充画风、画幅、成片时长目标、已有素材和预算。遗漏普通偏好时由主控选择；实际权限、现有额度和平台限制仍适用。只要剧本或方案时明确本轮范围。

Muse能实际读取GitHub文件时可直接给仓库链接；读取失败则上传独立指南文件或粘贴正文。不要把给了链接当成已经读完。该指南独立可读，不依赖Python或本地目录；实际持续执行、后期和任务隔离依赖Muse可用工具，尚未验证原生Skill安装。模板由主控内部填写。

## 在AI助手中使用

将整个仓库目录放到助手支持的技能目录，文件夹名保持 `muse-director`，保留子目录。Codex个人目录通常为 `~/.codex/skills/muse-director`；已有定制版本先比较，其他宿主按自己的规则载入。

调用：用 `$muse-director` 从我的主题/剧本开始负责Muse完整动画制作，普通选择自主推进，先交全片再接受修改。

入口是 [SKILL.md](SKILL.md)。Muse接入需要实际配置；无接入时只准备任务材料，不能宣称已出视频。本包不提供账户、私有API或后台执行器。

## 制作链路

```mermaid
flowchart LR
    A[用户给主题/大纲/剧本] --> B[Muse发展故事与分镜]
    B --> C[角色卡与必要参考]
    C --> D[内部代表样片检查]
    D --> E[独立旁聊或内部任务]
    E --> F[主控回收与检查]
    F --> G[自主选镜与有限修复]
    G --> H[剪辑混音与全片交付]
    H --> I[用户反馈]
    I --> G
    E --> J[报错先查状态与附件]
    J --> K[原额度内诊断或记录受阻]
    K --> F
```

旁聊与分镜是内部材料。不能连续看听时标未核验，完成可做制作后交完整候选；必要剧情缺失时明确部分作品，不用镜头清单或静图冒充全片。

## 本次实战反馈更新

- [拒收诊断](references/rejection-diagnostics.md)：先查任务状态与附件；错误原因未知时不猜定论。探针、拒收、换机位共用原额度，不自动执行三轮探针。
- 图像控制外观、文字保留必要辨识点与动作；冻结文案精简时同步升卡版本。
- 支持实际可用的旁聊或内部独立任务，真实引用与本地标签分开，由主控主动回收。
- [画内检查](references/shot-design-checks.md#画内物件文字与声音来源)：摄影器材、时代穿帮、叠加文字和画内品牌按采用设定检查；明确无Logo时品牌不自动豁免。
- 裁切/去标复核必要动作、画幅、取用窗口与接缝；不复制案例固定像素。
- 音轨注明真实来源，代码合成不称实录；10秒原片与30秒拼片不推断永久能力。
- 独立指南从共同参考/模板生成，修改源后重建并用 `scripts/build_muse_guide.py --check` 检查。

能力记录主要来自Muse自述与用户经验。技术检查、抽帧、连续动态、听音和用户认可分开报告；无能力的项目保留未核验。工具使用Python标准库；真实媒体技术检查需要FFprobe/FFmpeg。文本检查不能证明实际上传或动作生成正确。私人来源文档和视频不随仓库分发。
