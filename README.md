# 一句话成片 · muse-idea-to-short

让 Muse 把一句话、一段大纲或一段长提示词，做成30秒以上、多镜头、角色前后一致的短片。

**什么时候用**：要的片子超过10秒，需要拆成多镜再拼起来；或者有台词、有重复出现的角色。

**什么时候别用**：只要一条10秒左右的视频，直接给 Muse 就行（skill 也会识别出来，直接放行）。

**怎么发**：把[主文件](muse-idea-to-short.md)发给 Muse（读不了链接就把正文贴进去），再说你要什么。任何写法都可以：一句话、大纲、分段时间码、一整段英文提示词都行。Muse 会先交剧本、分镜表和全部资产（人物、场景、道具图），你回“可以”，它就一路做到交整片。不想确认就加一句“自主成片”。

**拿到片子先看**：人是不是同一个、镜头之间接得顺不顺、台词读得对不对（要自己听）、画幅对不对、结尾能不能看清主角。

**成本预期**：每镜平均要生成3–4次才得到1条可用，一条30秒的片子大约4镜、15次左右生成。慢，但是可控。

> 按《一句话成片》做一条30秒、竖屏9:16的治愈动画：蓝外套小兔把迷路的萤火虫带回灯笼。先给我剧本、分镜表和全部资产，我说可以之后就一直做到交整片。

## 新手按三层来，别跳级
1. **先玩转10秒**：让 Muse 做一条10秒的镜头，一个人、一个动作、一种运镜、一句台词。你会马上碰到真实问题：人对不对、台词有没有声音、镜头飘不飘。
2. **再用本 skill 跑通一条30秒的片子**：重点不是多精美，是把“资产先行、一次只改一处、保留失败版本”练熟。第一条一定会翻车，翻车记录最值钱。
3. **跑通之后再做系列**：人物跨集一致、风格统一、生产速度，这时才需要更多管理。

## 现在的流程（v3.2）
**剧本 → 分镜表 → 资产 → 锁定 → 首帧图 → 逐镜生成 → 拼接**

- **不替 Muse 写画面**：画面、运镜、音乐、节奏交给 Muse 自己发挥；在模型做得到的范围里找最好的解。
- **资产先行**：人物（面部特写＋全身照）、场景、道具图全部锁定后才开拍；锚点句每镜一字不改。
- **首帧图**：10/04 实测发现参考图会被当成首帧，输出比例也跟着它走。所以每镜先做一张比例正确、人物正确的首帧图，再让它动起来。
- **分镜**：一镜一种运镜，复杂动作放开场；情绪写成看得见的动作。
- **说话只用原生对白**：不走后期配音；人名加拼音注音；做不出来就改镜头设计。
- **返修一次只改一处**，每版提示词都保留，失败的也留，交片时一起附上。
- **只确认一次**：剧本、分镜表和全部资产一起确认。

流程中的六步法、资产先行、三层上手、原生对白红线、拼音注音、复杂动作放开场等做法，参考了 [Jarvis 的 Muse 漫剧实战文章](https://x.com/jarvis11x/status/2104397648438476868)。首帧图、单主体定妆图、看最后2秒等做法来自本项目10/04的实测。
