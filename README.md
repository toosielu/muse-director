# Muse 导演助手 · muse-director

给主题、简介、大纲或剧本，让Muse负责分镜、资产、旁聊任务、镜头选用、有限返修、剪辑混音，并交付完整动画。普通选择由主控决定，用户收到全片后再提修改。

Muse是视频制作方。Seedance文档、Hell Grind及总导演评审草稿只提供可迁移的方法：参考组织、身份常量、可见动作、局部返修和检查；按Muse当前实际能力使用。

## 直接交给Muse

打开 [Muse独立指南](assets/muse-self-director.md)，将文件或正文与主题/剧本一起交给Muse，并作为本项目的制作指令。

> 请阅读并采用这份《Muse导演助手》，负责完成完整动画。主题/剧本：……。普通创作、分镜、镜头选用、有限返修、剪辑混音由你自行决定。收齐旁聊结果后继续整合，不让我逐镜确认。请交可播放、可下载的全片，简短注明真实缺项和未核验项。

也可给画风、画幅、成片时长目标、已有素材和预算。普通偏好遗漏时由主控选择；真实权限、现有额度和平台限制仍适用。仅需剧本或方案时明确本轮范围。

该指南独立可读，不依赖本地目录或Python。实际读取、旁聊、持续执行和后期取决于Muse可用工具；尚未验证其原生Skill安装。模板由主控内部填写。

## 在AI助手中使用

将整个仓库目录放到助手支持的技能目录，文件夹名保持 `muse-director`，保留子目录。Codex默认个人目录通常为 `~/.codex/skills/muse-director`，已配置其他目录时使用相应位置。已有定制版本先比较。

调用：用 `$muse-director` 从我的主题/剧本开始负责Muse完整动画制作，普通选择自主推进，先交全片再接受修改。

入口是 [SKILL.md](SKILL.md)，其他宿主按自己的技能或指令规则载入。Muse接入方式需要实际配置；无接入时只准备任务材料，不能宣称已出视频。

## 制作链路

```mermaid
flowchart LR
    A[用户给主题/大纲/剧本] --> B[Muse主控发展故事与分镜]
    B --> C[统一角色卡与必要参考]
    C --> D[内部代表样片与输入检查]
    D --> E[独立旁聊生成各镜]
    E --> F[主控收齐、选用与有限返修]
    F --> G[剪辑、混音与可做检查]
    G --> H[交付完整动画]
    H --> I[用户反馈]
    I --> F
```

完整制作中，旁聊与分镜是内部材料。不能连续看听时标未核验，完成可做制作后交完整候选；必要剧情实际缺失时明确部分作品，不用镜头清单、字幕或静图冒充已完成全片。

## 本次改进

- 共享角色卡固定身份描述、风格与参考版本；每镜只另写动作和状态变化。
- 制作任务与模型输入分层，核对可见提交文字、主体数和实际参考顺序。
- 生成前检查输入，生成后按必要事件、身份、接缝和声音决定局部修复。
- 单次容量与拼接成片分开；约10秒是来源下的规划参考，未测硬上限保留未知。
- 换机位、拆镜或新旁聊不重置重试账本，必要剧情不因失败删除。
- 独立指南自动从共同参考/模板生成，维护后用 `scripts/build_muse_guide.py --check` 检查一致。

## 验证与能力边界

当前Muse能力记录主要来自其自述与用户经验，未独立复测。生成器图文输入、声音后期和审片能力分开记录；隐藏扩写或参数保持未知。技术检查、抽帧、连续动态、听音和用户认可分别报告。

本地工具使用Python标准库；真实媒体检查需要可用的FFprobe/FFmpeg。缺工具时相关项保留未检查。镜头检查器只验证文本与本地引用，不能证明Muse实际收到素材或动作生成正确。本包不提供视频生成服务、账户凭据或后台执行器。
